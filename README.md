# pareto_chart

pandas と Matplotlib
を使用して、表形式データから**パレート図を作成するシンプルなPythonユーティリティ**です。

CSVファイルからデータを読み込み、指定した列の項目ごとの出現回数を集計して、棒グラフと累積比率を組み合わせたパレート図を作成します。

このプログラムは、次の2通りの使い方ができます。

-   **単体アプリとして実行する**
-   **Pythonモジュールとして他のアプリから利用する**

Tkinterなどで作成したダッシュボードへ、グラフ作成機能を組み込む用途にも使用できます。

------------------------------------------------------------------------

## 特徴

-   CSVファイルを読み込んで分析
-   分析対象の列を選択可能
-   pandasを使用して項目ごとの件数を集計
-   Matplotlibでパレート図を作成
-   累積比率を折れ線グラフで表示
-   Matplotlibの`Figure`オブジェクトを返すため、他のアプリへ組み込み可能
-   単体アプリ／再利用可能なモジュールの両方に対応

------------------------------------------------------------------------

## 必要なライブラリ

-   Python 3
-   pandas
-   matplotlib

必要なライブラリは、次のコマンドでインストールできます。

``` bash
pip install pandas matplotlib
```

------------------------------------------------------------------------

## 使い方

### 1. 単体アプリとして使用する

`pareto_chart.py`を直接実行します。

``` bash
python pareto_chart.py
```

実行するとファイル選択ダイアログが表示されます。

1.  分析したいCSVファイルを選択します。
2.  CSVファイルに含まれる列がターミナルに表示されます。
3.  分析したい列の番号を入力します。
4.  選択した列を集計してパレート図を表示します。

------------------------------------------------------------------------

## CSVデータの例

付属の`sample.csv`は、次のような形式のデータです。

``` csv
measured_at,alarm_name
2026-09-01 08:15:12,非常停止
2026-09-01 09:03:25,センサー異常
2026-09-01 10:21:44,非常停止
2026-09-01 11:05:18,ワーク検出異常
```

`alarm_name`を分析対象として選択すると、アラーム名ごとの発生回数を集計し、パレート図として可視化できます。

設備のアラーム履歴だけでなく、不良項目、故障原因、トラブル内容など、**カテゴリごとの発生件数を分析したいデータ**に利用できます。

------------------------------------------------------------------------

## 2. Pythonモジュールとして使用する

`aggregate_data()`と`create_pareto_chart()`を他のPythonプログラムからインポートして使用できます。

``` python
from pareto_chart import aggregate_data, create_pareto_chart

result = aggregate_data(df, "alarm_name")
fig = create_pareto_chart(result, "alarm_name")
```

`aggregate_data()`でデータを集計し、`create_pareto_chart()`でパレート図を作成します。

`create_pareto_chart()`はMatplotlibの`Figure`オブジェクトを返すため、作成したグラフをTkinterなどのGUIアプリへ埋め込むことができます。

------------------------------------------------------------------------

## Tkinterへの組み込み例

``` python
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg

canvas = FigureCanvasTkAgg(fig, master=parent_frame)
canvas.draw()
canvas.get_tk_widget().pack(fill="both", expand=True)
```

このようにすることで、`pareto_chart.py`をダッシュボードアプリのグラフ作成モジュールとして利用できます。

## sample.csvについて

動作確認用として`sample.csv`を用意しています。

主な列は次のとおりです。

  列名            内容
  --------------- ------------------------
  `measured_at`   データが記録された日時
  `alarm_name`    アラーム名

独自のCSVファイルを使用することもできます。

発生回数を集計したいカテゴリ列を選択してください。

## 想定用途

例えば、次のような分析に利用できます。

-   設備アラームの発生回数分析
-   不良項目の分析
-   故障原因の分析
-   品質トラブルの分析
-   生産設備のトラブル分析
-   その他、カテゴリ別の発生件数分析

特に、**「どの項目から優先的に対策すべきか」を把握するためのパレート分析**に利用できます。

## プログラム構成

このプログラムでは、**データの集計処理**と**グラフ作成処理**を分離しています。

``` text
CSV / DataFrame
      ↓
aggregate_data()
      ↓
集計データ
      ↓
create_pareto_chart()
      ↓
Matplotlib Figure
```

処理を分けることで、単体アプリとして使用するだけでなく、Tkinterなどの別アプリからグラフ作成機能だけを再利用しやすい構成にしています。
